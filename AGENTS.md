# champ-boxing

Пет-проект: сайт клуба бокса CHAMP BOXING CLUB на русском языке. Проект ведётся в OpenCode; рабочие правила из глобального конфига Спектрума не применяются — процесс, скиллы и агенты настроены прямо здесь.

## Процесс

- Процесс (v2, четыре гейта): docs/process/workflow.md
- Текущее состояние: docs/process/status.md — читай перед любой работой над сайтом.
- Управление: `/pipeline status`, `/pipeline next`, `/pipeline approve G3`, `/pipeline rework G1 что изменить`. Состоянием гейтов управляет только скрипт `.agents/skills/pipeline/scripts/gate.mjs`; файлы status.json и status.md вручную не редактируются, блокировку скрипта обходить нельзя.
- Работу делает основная сессия; независимая проверка перед утверждением гейта — субагент `reviewer` (.opencode/agent/).

## Правила

- Сайт только на русском. Стек: Astro + TypeScript + Tailwind CSS, статический вывод, без серверной части.
- Заявки — deep-ссылки WhatsApp и телефон, как на старом сайте. Форм и серверных обработчиков нет.
- Код сайта — `src/` (гейт G3); прототипы — только в docs/design/drafts/. Сборка, адреса и деплой — README.md.
- Две цели сборки: `prod` — champ-box.ru в корне, `preview` — gussy-pussy.ru/champ-box/ (noindex, без Метрики). Пути в разметке — только через `withBase()` (src/lib/base.ts); проверка путей — `npm run build:preview`.
- Аналитика — Яндекс Метрика (без Вебвизора), только после согласия в cookie-баннере. Новая интеграция или сбор данных → сначала правка политики (docs/copy/privacy.md и src/pages/privacy.astro).
- Деплой (`./deploy.sh`) — только по явной просьбе пользователя.
- Утверждает только пользователь, явным словом; `/pipeline approve` передаёт его фразу дословно.
- Факты о бизнесе не придумываются. Отсутствующее помечается [ПОДТВЕРДИТЬ], примеры — [ПРИМЕР].
- Изображения — только через `node .agents/skills/pipeline/scripts/image.mjs` (ChatGPT): реальные фото клуба обрабатываются под студию, генеративные люди — только иллюстративные сцены, не как тренеры или клиенты клуба.
- Факты о клубе — docs/brief/brief.md и src/data/site.ts; старый сайт (`old_site.html`, `old_site_files/`) удалён из репозитория 07.11.2026, доступен в истории git: `git show ab171f3:old_site.html`, `git checkout ab171f3 -- old_site_files`.
- Коммиты — только по явной просьбе пользователя.
