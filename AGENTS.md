# champ-boxing

Сайт только на русском языке. Создаётся по поэтапному процессу с гейтами утверждения.

- Процесс, роли и модели: docs/process/workflow.md
- Текущее состояние: docs/process/status.md, читай перед любой работой над сайтом.
- Выбор скиллов и причины: docs/process/skills-decision.md
- Управление: `$pipeline status`, `$pipeline next`, `$pipeline approve G3`, `$pipeline rework G5 что изменить`.

## Правила

- Код сайта не пишется до утверждения G7. Визуальные решения принимаются в Figma.
- Утверждает только пользователь, явным словом. Статус фиксируется в docs/process/status.md.
- Основная сессия выступает оркестратором: общается с пользователем и запускает агентов из .codex/agents/ по имени.
- Направление дизайна задаётся один раз, на G3. После этого $impeccable не предлагает новые направления.
- Чтение Figma через MCP экономится: лимит очень мал. Разработка и проверка работают по файлам в docs/design/.
- Факты о бизнесе не придумываются. Отсутствующее помечается [ПОДТВЕРДИТЬ], примеры помечаются [ПРИМЕР].
