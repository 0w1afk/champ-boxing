# champ-boxing

Пет-проект: сайт клуба бокса CHAMP BOXING CLUB на русском языке. Проект ведётся в OpenCode; рабочие правила из глобального конфига Спектрума не применяются — процесс, скиллы и агенты настроены прямо здесь.

## Процесс

- Процесс и роли: docs/process/workflow.md
- Текущее состояние: docs/process/status.md — читай перед любой работой над сайтом.
- Управление: `/pipeline status`, `/pipeline next`, `/pipeline approve G5`, `/pipeline rework G4 что изменить`. Состоянием гейтов управляет только скрипт `.agents/skills/pipeline/scripts/gate.mjs`; файлы status.json и status.md вручную не редактируются, блокировку скрипта обходить нельзя.
- Роли — субагенты проекта: `.opencode/agent/` (marketer, copywriter, designer, frontend, reviewer).

## Правила

- Сайт только на русском. Стек: Astro + TypeScript + Tailwind CSS, статический вывод, без серверной части.
- Заявки — deep-ссылки WhatsApp и телефон, как в старом сайте (old_site.html). Форм и серверных обработчиков нет.
- Код сайта не пишется до утверждения G7. До этого — только прототипы в docs/design/drafts/.
- Утверждает только пользователь, явным словом; `/pipeline approve` передаёт его фразу дословно.
- Факты о бизнесе не придумываются. Отсутствующее помечается [ПОДТВЕРДИТЬ], примеры — [ПРИМЕР].
- Изображения — только через `node .agents/skills/pipeline/scripts/image.mjs` (ChatGPT): реальные фото из old_site_files/ обрабатываются под студию, генеративные люди — только иллюстративные сцены, не как тренеры или клиенты клуба.
- `workspace-784888f5-982a-47ad-b35d-9e5f9d2e4958/` — референс: контент и изображения не используются, образы тренеров и клиентов оттуда запрещены.
- Коммиты — только по явной просьбе пользователя.
