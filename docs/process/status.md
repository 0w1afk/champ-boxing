## S9: запуск

- [ ] `error-pages` Страницы 404 и общей ошибки сервера оформлены и отдают верные коды ответа
- [ ] `robots` robots.txt разрешает индексацию на боевом домене и запрещает на тестовом
- [ ] `sitemap` sitemap.xml создан, содержит все страницы и указан в robots.txt
- [ ] `meta-social` Open Graph, canonical и favicon проверены на всех страницах
- [ ] `lead` Ссылки записи открывают WhatsApp с предзаполненным сообщением и телефон; поведение при недоступности мессенджера предусмотрено
- [ ] `analytics` Аналитика подключена, цели из стратегии срабатывают
- [ ] `consent` Согласия на обработку персональных данных и cookies соответствуют фактически собираемым данным
- [ ] `privacy` Политика конфиденциальности опубликована и доступна с каждого места записи; требования 152-ФЗ проверены ответственным лицом
- [ ] `domain-https` Домен подключён, HTTPS действует, настроены редиректы с http и основного зеркала
- [ ] `integration-failures` При отказе внешних встраиваемых сервисов (карта, виджеты, мессенджер) страница работает и показывает понятное сообщение
