# Процесс (v2, для лендингов)

Процесс ведёт основная сессия OpenCode: сама делает работу, изображения — через ChatGPT (`image.mjs`), независимая проверка — субагент-ревьюер. Четыре гейта, дальше итерации. Правила переходов проверяет скрипт, а не модель.

Команды: `/pipeline status`, `/pipeline next`, `/pipeline approve G2`, `/pipeline rework G1 что изменить`. Напрямую: `node .agents/skills/pipeline/scripts/gate.mjs …`.

## Гейты

| Гейт | Этап | Что сдаётся | Материалы |
|---|---|---|---|
| **G1 Концепция** | S1 | Идея, структура, тексты всех страниц | `docs/design/concept.md`, `docs/copy/*.md` |
| **G2 Основа** | S2 | Токены + HTML-прототип основы + база движения | `docs/design/tokens.json` (+ прототип в `docs/design/drafts/foundation/`) |
| **G3 Сайт** | S3 | Все страницы в Astro, собранные и проверенные | `docs/review/site/qa.md`, `docs/review/site/review.md` |
| **G4 Запуск** | S4 | Публикация: домен, robots, sitemap, метрики | `docs/review/release/qa.md`, `docs/review/release/review.md`, чек-лист s9 |

После утверждения G3 проект живёт в режиме итераций: правки без гейтов — сделал, показал, коммит по просьбе. Итерация, меняющая концепцию или основу целиком, оформляется `rework G1`/`rework G2`.

## Как проверяются переходы

Скрипт `.agents/skills/pipeline/scripts/gate.mjs` пишет `docs/process/status.json` и генерирует `docs/process/status.md` — вручную их не редактировать, блокировку не обходить.

| Переход | Скрипт проверяет |
|---|---|
| `start` | статус «не начато» или «устарело»; вся цепочка предыдущих гейтов утверждена |
| `submit` | статус «в работе» или «на доработке»; материалы существуют и не пусты |
| `approve` | статус «на утверждении»; материалы на месте; передана дословная фраза пользователя |
| `rework` | указана причина; гейт «утверждено», «на утверждении» или «на доработке» |

`rework G1` делает устаревшими G2–G4, `rework G2` — G3 и G4, `rework G3` — G4. При устаревании G4 чек-лист запуска сбрасывается. Тесты: `node --test ".agents/skills/pipeline/scripts/gate.test.mjs"`.

## Кто делает

| Работа | Кто |
|---|---|
| Концепция, тексты, токены, прототип, код | основная сессия |
| Изображения | `image.mjs` → ChatGPT: реальные фото клуба из `old_site_files/` обрабатываются под студию; генеративные люди — только иллюстративно, не как тренеры и клиенты |
| Проверка перед утверждением гейта | субагент `reviewer` (`.opencode/agent/reviewer.md`), один проход |

Правки по находкам ревьюера основная сессия делает сама, затем ревьюер перепроверяет. Больше двух кругов — остаток выносится пользователю как есть.

## Цикл G3 (сайт)

1. Собрать все страницы в Astro + TypeScript + Tailwind по токенам и концепции; тексты — дословно из `docs/copy/`.
2. Механические проверки: сборка без ошибок, нет горизонтального скролла на 390/768/1440, фокус виден, `prefers-reduced-motion`, ссылки WhatsApp/tel, ошибки консоли. Факты — в `docs/review/site/qa.md`.
3. Ревьюер: сверка с концепцией и токенами, вердикт с доказательствами — в `docs/review/site/review.md`.
4. Правки, `submit G3`, утверждение пользователем.

## G4 (запуск)

Чек-лист `s9` закрывается с доказательствами (`gate item s9 <пункт> --note`), неприменимое — `--na`. Проверки, зависящие от домена, — на боевом домене. Юридические тексты подтверждает ответственный человек.

## Изображения

`image.mjs` запускает Codex из приложения ChatGPT вне репозитория; файл и промпт сохраняются в `docs/design/generated/`, готовое не перезаписывается. Результат показывается пользователю до использования.
