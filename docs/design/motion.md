# Спецификация движения

Статус: заготовка для G6 — составлена по экрану home (G6.home); после экранов privacy и error дополняется их переходами и утверждается на G6. Принципы: движение имеет назначение; один вау-момент; только transform/opacity; всё имеет вариант reduced-motion; hover-стили — только на точных указателях (`(hover: hover) and (pointer: fine)`). Базовые длительности и кривые — `docs/design/tokens.json` → `motion`.

## Общие правила

- Анимация без назначения не попадает в спецификацию.
- Reveal-появление — один раз за сессию (IntersectionObserver), без повторов при обратном скролле.
- Параллакс — только transform/opacity, scroll-driven; не конкурирует с чтением.
- Ничто не блокирует контент и действия: reduced motion даёт содержательную статику.
- Трасса прокрутки и якорные переходы (`#formats`, `#start`, `#faq`, `#prices`) работают без ожидания анимации.

## Исключено (решения G3/кругов ревью)

- Кастомный курсор — не переносится; системный курсор везде.
- Halftone-растр — исключён вместе с комикс-подачей; остаётся только плёночное зерно (статичное, не анимируется).
- Появление «на каждой секции» — не делаем: reveal один раз, параллакс только первого экрана.
- Анимация клика по ссылке записи (переход в WhatsApp внешним приложением) — не имитируется: состояние «заявка отправлена» не существует.

## Что уточняется на G6 (после privacy и error)

- Переходы служебных экранов (404/500, политика): появление контента, состояния ссылок.
- Открытие/закрытие мобильного меню: панель (transform/opacity), длительность 300 ms, standard-кривая; Escape и возврат фокуса — без анимации фокуса.
- Точки срабатывания reveal (порог IntersectionObserver, rootMargin) — фиксируются при сборке S8 по этой таблице.
