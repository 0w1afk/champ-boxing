## 4. Тренеры

Заголовок блока «Тренеры CHAMP» (из G4); сцена — «Начни в своём темпе.», подпись команды, «Спарринги — не сразу и только по желанию.», действия «Познакомиться с тренерами · Как проходит первое занятие · Частые вопросы».

Карточка: фото + имя (h3) + тизер-регалия + `details` (выравнивание низа: `flex-1` у блока текста, `mt-auto` у details). Биографии дословно, NBSP сохранены (3/4/4/5/5). Действие карточки — Label in Name (WCAG 2.5.3): видимый текст переключается через `details[open]` без JS — закрыто: «Подробнее о тренере», открыто: «Закрыть карточку тренера» (оба дословно из G4); имя тренера — sr-only продолжение «: {имя и фамилия}». Доступное имя следует за состоянием (`display:none` исключает спан из accname): закрыто — «Подробнее о тренере: {имя}», открыто — «Закрыть карточку тренера: {имя}»; видимый текст в обоих состояниях входит в доступное имя. Открытая карточка-образец — Евгений Лелеков. На S8 допустима динамическая реализация с теми же текстами.

Фото: сырые `old_site_files/{evgeny-lelekov,viktor-kirichenko,konstantin-kasyanov,viktor-martynov,roman-efanov}_uweO.jpg`, относительные пути `../../../../old_site_files/…`; студийная обработка — S7/S8 [ПОДТВЕРДИТЬ], до обработки в прод не идут. Генеративные люди запрещены.

## 5. Стоимость: две раскладки

- `<768` — строки-блоки (формат; «Разовое — X · 12 занятий — Y»), числа tabular-nums с NBSP, не режутся.
- `≥768` — таблица: «Формат / Разовое занятие / 12 занятий», выравнивание чисел вправо, строки с `border-line`.
На S8 — одна разметка с CSS-переключением; состав данных один.

## 6. Состояния и переходы

| Состояние | Поведение | Реализация |
|---|---|---|
| Формат закрыт/открыт | знак +/×; доступное имя — действие из G4 (aria-label summary) | `details[open]`, CSS-знак |
| FAQ закрыт/открыт | вопрос — имя кнопки; один открыт как образец | `details[open]` |
| Карточка тренера | тизер → биография; видимый текст действия и доступное имя следуют за состоянием: «Подробнее о тренере: {имя}» ↔ «Закрыть карточку тренера: {имя}» (Label in Name) | `details[open]` + CSS-переключение спанов; на S8 — то же поведение |
| Меню закрыто/открыто | бургер ↔ крест; в открытом: пункты, CTA, условие, политика, «Позвонить…» | прототип — статичный образец (кнопка «Открыть меню» без обработчика, подписана в приложении); S8 — TS-логика: Escape, фокус-ловушка, возврат к инициатору |
| Карта не загрузилась | «Не удалось загрузить карту. Адрес: … Построить маршрут.» | фолбэк-блок в контактах; сервис — S9 [ПОДТВЕРДИТЬ] |
| WhatsApp недоступен | «Не получается открыть WhatsApp? Позвоните: +7 (914) 423-45-55.» + «Позвонить» (tel:) | приложение «Состояния»; телефон доступен всегда |
| Кнопка primary | default 5.34:1 → hover #ff7a1f 7.59:1 → pressed #d94e0d + scale(0.97) 4.75:1 → focus-visible outline 2 px #ff7a1f offset 3 px → disabled 5.13:1 | states из tokens.json |
| Фокус на текстовых ссылках и summary | тот же токен focusRing (2 px bright, offset 3 px), не браузерное дефолтное | `focus-visible:outline-*` на всех интерактивных |
| Условие у CTA | связано программно | `aria-describedby` |
| Тикер | marquee 32 s; пауза на hover (точные указатели); кнопка «Пауза/Продолжить» (aria «Пауза тикера»/«Продолжить тикер»); вторая копия aria-hidden | CSS + единственный JS прототипа |
| Пропуск сцены | «Перейти к форматам» → `#formats` без анимации | anchor + reduced-motion |
| Пропуск контента | «Перейти к содержимому» → `#main` | skip-link |

**Движение — вне прототипа.** Параллакс первого экрана, reveal-появления, магнитная кнопка в статичный HTML не входят и JS-ом не эмулируются: их назначение, свойства, длительности и кривые — `docs/design/motion.md` (утверждается на G6), реализация — S8. В прототипе единственный JS — пауза тикера (демонстрация состояния).

Клавиатура: все действия — ссылки/кнопки/summary с видимым фокусом по токену. Модальных окон нет; раскрытия — нативные details, место прокрутки сохраняется.

## 7. Адаптив 1440 / 1024 / 390

- **1440**: контейнер 1360; хук — 9/12 с xl (1012 px), 90 px, две строки; hero: типографика 9 кол + заглушка 3 кол; карточки тренеров 5/3/2 по брейкпоинтам; таблица цен полная.
- **1024**: хук — все 12 колонок (до xl), две строки; hero в одну колонку.
- **390**: поля 20; хук 36 px, две строки; шапка — лого + бургер; CTA full-width; формат-строки — grid 12 колонок с переносами; цены — строки-блоки (§5); карточки тренеров в колонку, низ карточек выровнен; тикер 13 px, 8 фактов.
- Контурное слово — полоса 110/200 px, clamp(96px, 22vw, 280px), вне зоны текста и кнопок.
- Проверено рендером (headless Chrome, контроль круга 2): 1440/390 — scrollWidth = вьюпорт; все CTA — wa.me/tel; фокус по токену на всех интерактивных, включая skip-link; Label in Name карточек тренера в обоих состояниях; подписи цен полные («Разовое занятие»); дубли меток раскрытий отсутствуют; 5 фото загружаются.
