# G5 — одноразовый браузерный стенд

Концепция: «Один жест». Этот дизайн-артефакт не копируется в продукт. Полноценные экраны G6 ещё не создаются.

Запуск без зависимостей и изменения package.json:

```sh
python3 -m http.server 58505 --bind 127.0.0.1 --directory docs/design/drafts/g5-foundation
```

Открыть `http://127.0.0.1:58505/`. Проверять на ширинах 1440, 768 и 390.

В стенде: три схемы с переключением, локальные Oswald/Golos Text с кириллицей, шкала типографики, CTA/вторичное действие/меню с состояниями, доступный dialog с настоящими текстами, fallback карты и мессенджера, схемы сеток и отступы. Кнопки записи открывают демонстрацию первого занятия, внешние переходы отключены.

Шрифты получены из официального Google Fonts CSS API и fonts.gstatic.com. Файлы TTF включают кириллицу. Лицензии семейств — SIL Open Font License, их следует повторно приложить к финальным self-hosted ресурсам при реализации S8. В Figma оба семейства уже найдены в штатном каталоге в предыдущем незавершённом проходе.

Обзорные изображения после проверки находятся в `captures/`. Точный источник токенов: `docs/design/tokens.json`. Перед переносом пользователь должен явно утвердить HTML-прототип.
