# Прототип экрана home — S6 / G6.home

Дизайн-артефакт. Не копируется в продукт: сборка на S8 по `docs/design/screens/home.md` и `docs/design/tokens.json`. Тексты — дословно `docs/copy/home.md` (NBSP сохранены). Основа — утверждённая G5: `../g5-foundation-v2/`.

## Запуск

```sh
# из корня репозитория (важно для относительных путей фото ../../../../old_site_files/…)
python3 -m http.server 58507 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:58507/docs/design/drafts/home/`. Работает и открытие `index.html` с диска (file://). Внешние зависимости: Tailwind CDN и Google Fonts.

## Состав

`index.html` — полный экран home: шапка (лого `logo.svg`, навигация, CTA), первый экран с хуком и тикером (пауза — единственный JS), сцены по карте G2: `#experience`, `#formats` (6 раскрытий, «Общая группа» открыта как образец), `#coaches` (5 карточек с реальными фото из `old_site_files` — сырые, обработка S7/S8), `#start`, `#prices` (таблица со сплитом на ≥768, строки-блоки на 390), `#faq` (9 вопросов, один открыт), `#contacts` (карта-заглушка с фолбэком), футер; приложение «Состояния» (открытое мобильное меню, состояния кнопок, фолбэк WhatsApp). Ссылки записи — deep-ссылки WhatsApp (`wa.me` с сообщениями из G4 у форматов), телефоны — `tel:`. Desktop 1440 / mobile 390 — один адаптивный файл, без JS-логики (кроме паузы тикера), reduced-motion учтён.

## Проверка (headless Chrome)

```sh
node verify.mjs <путь>/node_modules/playwright/index.mjs
```

Проверяет: хук — 1 rect на строку на 1024/1280/1440, wa.me/tel у всех CTA; scrollWidth = вьюпорт на 1440/1024/390; 8 фактов тикера и пауза; кириллица (Oswald; Ж/Щ/Ё); фокус на skip-link; 5 фото загружаются; details (6 форматов/1 открыт, 9 FAQ/1 открыт, 5 тренеров); якоря карты. Результат: `verify-result.json`, снимки: `captures/`.
