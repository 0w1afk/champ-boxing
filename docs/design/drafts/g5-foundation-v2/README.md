# G5 основа v2 — «Макро-нуар»

Дизайн-артефакт этапа S5 (гейт G5). Не копируется в продукт. Предыдущий черновик `../g5-foundation/` устарел (красная палитра, хук «НАЧНИ.») и сохраняется рядом как история. Ревизия по ревью от 2026-11-05: хук — ровно две строки на 1024–1440 (до 1280 все 12 колонок, с 1280 — 9/12, максимум 90 px, tracking −0.01em); контурное слово выведено из зоны текста и кнопок в нижнюю свободную полосу; мобильные размеры синхронизированы с tokens.json; доступные имена дословно по G4 (логотип — «CHAMP BOXING CLUB — на главную», NBSP в биографиях сохранены); pressed — scale(0.97) + #d94e0d; тикер — полный набор из 8 фактов на всех брейкпоинтах.

Запуск без зависимостей:

```sh
python3 -m http.server 58506 --bind 127.0.0.1 --directory docs/design/drafts/g5-foundation-v2
```

Открыть `http://127.0.0.1:58506/` (или просто открыть `index.html` в браузере — внешние зависимости: Tailwind CDN и Google Fonts).

Внутри: первый экран desktop 1440 и mobile 390 (шапка, хук «БИТЬ НЕ БУДЕМ. / ПОКА НЕ ПОПРОСИШЬ.», CTA с условием, заглушки изображений, контурная полоса «Бокс», тикер), тикер с вариантом reduced motion и рабочей кнопкой «Пауза/Продолжить» (единственный инлайн-JS стенда — демонстрация состояния), типографическая шкала Oswald/Manrope на реальных заголовках с Ж, Щ, Ё, палитра свотчами с измеренным контрастом, компоненты во всех состояниях. Тексты — только из утверждённого `docs/copy/home.md`; пометки [ПОДТВЕРДИТЬ] и [ПРИМЕР] видны в макете.

Точное значение токенов: `docs/design/tokens.json`. Числа контраста воспроизводятся: `node contrast.mjs`.

Проверка в headless Chrome (hook 1 rect на строку на 1024/1280/1440, scrollWidth = вьюпорт на 1024/1280/1440/768/390, тикер 8/8, NBSP биографий, отсутствие пересечений контурного слова с текстом, aria-имена, кнопка паузы):

```sh
node verify.mjs <путь>/node_modules/playwright/index.mjs   # браузер: channel: 'chrome'
```

Результат последнего прогона: `verify-result.json`, обзорные снимки: `captures/`.
